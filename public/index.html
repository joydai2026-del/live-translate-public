Live interpreting between two phones

Speak here. They read it there.

Start a room on this device, then hand the code or QR to the other person. What you say appears on their screen, translated, a moment later. You can download the whole conversation as a bilingual transcript.

Which way are you translating?

  1. Start a room. This device becomes the microphone.
  2. The other person scans the QR or types the code on their phone.
  3. Hold the talk button and speak. They read the translation and can reply from their phone.

Speech recognition needs Chrome, Edge or Safari. You can also type instead of speaking.

Did someone give you a code? Join their room and read along.

Privacy: Chrome and Edge send the speaker's audio to Google or Microsoft for speech recognition, and Safari may send it to Apple; this server never receives audio. The recognized text, and every reply the guest types or speaks, is sent to this server and to the translation provider named above, and stored the same way. Anyone with the room code can read along. Only the device that started the room can download the transcript. Rooms are kept in memory only and are deleted after 12 hours idle or when the server restarts.
