    Speech recognition runs in the speaker's browser: Chrome and Edge send the audio to Google or Microsoft, and Safari may send it to Apple. This server never receives audio. The recognized text and your replies go to this server and to the translation service named above. Anyone with the room code can read along. The speaker can download the transcript; there is no download on this page. Rooms are kept in memory only and are deleted after 12 hours idle or when the server restarts.
