# T2 UI (design-focused)
Goal: beautiful, calm, very legible UI for public/ pages (/, /host/:code, /j/:code, /join) so `bash checks/slow.sh` passes (checks/e2e.mjs defines required data-test hooks: start-both, room-code, qr, code-input, join, lang-en, lang-zh, download-md; window.__liveTranslateTest.feed).
Host: big mic button using Web Speech API (webkitSpeechRecognition, continuous, interimResults, lang en-US or zh-CN toggle via lang-en/lang-zh), shows code large + QR + join URL, live transcript with both languages, download transcript (md, txt, json), clear message when the browser lacks Web Speech (e.g. Firefox) suggesting Chrome/Edge/Safari, and a text box fallback to type. Guest (phone): huge readable translated text, newest at bottom, auto-scroll, small original text under each, font size toggle, wake-lock request, reconnect on drop, "waiting for speaker" state. Home: pick direction (English to Chinese, Chinese to English, both). Footer: which translation provider is active (from GET /api/config, add it) and a privacy note (audio is processed by the browser's speech service; text goes to the translation provider).
Mobile first, Chinese font stack (PingFang SC, Noto Sans SC), accessible contrast, no em dashes, no external CDNs.
Don't touch: checks/, server logic except adding /api/config and serving pages. Check: `npm test` then `bash checks/slow.sh`; look at the evidence/ screenshots yourself (Read them) and polish until they look great.
