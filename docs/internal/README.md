# Build notes (internal)

These files are the working notes from how this app was built and reviewed: review rounds (REVIEW-R1.md, REVIEW-R2.md), the pre-publish QA report (QA.md), task briefs (tasks/) and the planner's fix notes (planfix-notes.md). They used to sit at the repo root; comments in `checks/` still refer to them by their old root paths (for example `tasks/T4-grill.md` is now `docs/internal/tasks/T4-grill.md`).

They are kept for history. Nothing in the app or the tests reads them.
